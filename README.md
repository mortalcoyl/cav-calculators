# Real Estate Calculators — Separate Pages

This package uses Next.js App Router with separate URLs for each calculator.

## Routes

- `/` — Landing page
- `/rent-vs-buy` — Renting vs. Buying
- `/rental-property-eval` — Rental Property Eval
- `/auto-cost` — Auto Cost Calculator
- `/bat` — Bring a Trailer Decision
- `/home-value-vs-market` — Home Value vs. Market Investment

## Local setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
```

## Deploy on Vercel

1. Upload this folder to GitHub or import it directly into Vercel.
2. Vercel should auto-detect Next.js.
3. Build command: `npm run build`
4. Output directory: leave blank/default.
